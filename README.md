# Digit Maxz - Digital Marketing & AI-Powered Growth Platform

A high-converting website and technology stack for Digit Maxz, featuring separated frontend and backend architectures.

## Project Structure

- `frontend/` - Static UI pages, CSS design system, micro-animations, ROI calculator, and interactive lead funnels powered by Vite.
- `backend/` - Node.js Express server handling API requests and lead captures.

## Getting Started

### 1. Frontend
```bash
cd frontend
npm install
npm run dev
```

### 2. Backend
```bash
cd backend
npm install
npm run dev
```
